# Cat Meme Picker

A fun interactive web application that lets users select a mood and displays a cat meme that matches the selected mood.

## Features

- Select a mood from the available options
- Display a cat meme based on the selected mood
- Interactive user interface
- Dynamic content rendering
- Simple and responsive design

## How It Works

1. Select a mood from the available options.
2. The application finds cat memes associated with that mood.
3. A matching cat meme is displayed to the user.

## Tech Stack

- HTML5
- CSS3
- JavaScript
